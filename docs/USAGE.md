# Консольные команды

Работа через сайт описана в [ИНСТРУКЦИЯ.md](../ИНСТРУКЦИЯ.md). Здесь — то же из командной строки:
для пакетной обработки, экспериментов и отладки. Команды запускаются из корня репозитория.

Команды `run`, `krgen.evaluate` и `krgen.experiment` обращаются к модели и расходуют подписку
(кроме ответов, которые уже есть в кэше). Остальные работают только с базой.

## Веб-интерфейс

```bash
python -m krgen.server
```

Сервер слушает http://127.0.0.1:8765. На другом порту:
`python -m uvicorn krgen.server:app --port 8766`.

## krgen.cli

| Команда | Что делает |
|---|---|
| `init --title "…" --icd S52.5 S52.6 [--age adults\|children\|mixed] [--org "…"] [--id myproj]` | создать проект, печатает его id. По умолчанию `--age mixed` |
| `add <проект> файл1.pdf файл2.pdf …` | загрузить PDF; для каждого печатает id, статус и число страниц |
| `run <проект>` | все этапы: keywords, extract, verify, group, resolve, kr |
| `run <проект> --stages group resolve kr` | только сборка КР (как «Собрать КР заново») |
| `run <проект> --only-failed` | повторить только фрагменты, которые не обработались |
| `run <проект> --docs <id> <id>` | извлекать факты только из указанных документов |
| `run <проект> --no-judge` | без модели-рецензента: факты без готового вердикта останутся «на проверке» |
| `report <проект>` | отчёт об обработке в JSON: покрытие страниц, запросы, токены, стоимость, ошибки |
| `snapshot <проект> [--run <id прогона>]` | заново сохранить снимок последнего (или указанного) прогона |
| `export <проект> <папка>` | выгрузить КР: Word, Markdown, полный JSON и JSON по схеме kr_recommendation, плюс файлы с результатом проверки по схемам |

Пример:

```bash
python -m krgen.cli init --id myproj --title "Переломы дистального отдела костей предплечья" --icd S52.5 S52.6 S52.8 --org "АТОР"
python -m krgen.cli add myproj "Статьи Разбор клинреков/311.pdf" "Статьи Разбор клинреков/588.pdf"
python -m krgen.cli run myproj
python -m krgen.cli export myproj out
```

## Оценка и эксперименты

| Команда | Что делает |
|---|---|
| `python -m krgen.evaluate <проект> gold/example_gold_p1.json` | точность, полнота и F1 извлечения по эталону; результат в `data/eval/` |
| `python -m krgen.evaluate <проект> <эталон> --extras-review data/eval/<проект>_extras_for_review.csv` | то же с учётом разметки «лишних» фактов (см. [ANNOTATION_GUIDE.md](ANNOTATION_GUIDE.md)) |
| `python -m krgen.experiment experiments/thinking_and_gate.json` | сравнение вариантов настроек на одном наборе PDF; результат в `data/experiments/` |

## Отладка

| Команда | Что делает |
|---|---|
| `python tests/test_pipeline_stub.py` | сквозной тест всех этапов и API с заглушкой вместо модели, подписку не расходует |
| `KRGEN_FAIL_AFTER=5 python -m krgen.cli run <проект>` | после 5 запросов модель «отказывает»: проверка, что полученное сохраняется и повторный запуск доделывает остальное |
