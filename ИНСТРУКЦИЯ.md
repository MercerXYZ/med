# KRGen: генерация черновика КР с нуля

## 0. Перед началом

**Нужен вход в Claude.** Программа работает на вашей подписке Claude, API-ключ не нужен. Если модель
отвечает «OAuth session expired» или «not logged in», выполните в терминале:

```
claude auth login
```

**Сколько это стоит.** Обработка с пустого кэша:

| Объём | Время | Расход (эквивалент API, тратятся лимиты подписки) |
|---|---|---|
| 1 короткая статья (5–15 стр.) | 2–4 мин | ≈ $0.3–1 |
| 3–5 статей | 10–20 мин | ≈ $2–4 |
| весь корпус (33 файла) | 2–3 часа | ≈ $30, скорее всего упрётся в лимит подписки |

Для показа процесса начните с 3–5 коротких статей, например `311.pdf`, `588.pdf`,
`Caruso_и_др_2019_…pdf`, `Firth_и_Robertson_2017_…pdf`, `minimally_angulated_pediatric_wrist_fractures_…pdf`.
Статьи можно добавлять позже: уже обработанное повторно не оплачивается, ответы модели кэшируются.

## 1. Обнулить результаты (старый демо-проект сохраняется)

Все результаты и кэш ответов модели лежат в папке `data`. Не удаляйте её, а переименуйте:
это резервная копия готового демо, которую можно вернуть для показа преподавателю.

1. Остановите сервер, если он запущен: Ctrl+C в окне, где он работает, или закройте это окно.
   Пока сервер работает, Windows не даст переименовать папку.
2. Переименуйте папку `data` в `data_demo_backup`.
3. Новая пустая `data` создастся сама при запуске сервера.

**Вернуть старое демо:** остановить сервер, переименовать `data` в `data_new`,
а `data_demo_backup` обратно в `data`.

> Если нужен быстрый показ без новых расходов: не переименовывайте `data`, а просто создайте
> новый проект (шаг 3) и загрузите те же статьи. Почти всё возьмётся из кэша за минуту, но это
> будет повтор, а не настоящая генерация.

## 2. Запустить программу

В папке проекта (`C:\Users\Savki\Desktop\Med`):

```
python -m krgen.server
```

Откройте в браузере http://127.0.0.1:8765. Окно с сервером не закрывайте, пока работаете.

## 3. Создать проект

Кнопка **«+ Проект»** вверху справа. Поля уже заполнены под нашу тему:
- тема — «Переломы дистального отдела костей предплечья»;
- возрастная группа — взрослые и дети;
- коды МКБ-10 через запятую — S52.5, S52.6, …;
- организация.

Нажмите **«Создать»**. Если код МКБ указан с ошибкой, появится сообщение, а окно останется открытым.

## 4. Загрузить статьи

Вкладка **«Документы»**: перетащите PDF из папки `Статьи Разбор клинреков` или выберите их кнопкой.
Сразу видно число страниц. Одинаковые файлы помечаются как дубликаты, сканы без текста — как
необработанные.

## 5. Запустить обработку

Кнопка **«▶ Обработать»** в шапке проекта. Галочки:
- **LLM-рецензент** — оставьте включённой. Это смысловая проверка карточек: она даёт +12 п.п.
  точности.
- **Только сбойные фрагменты** — нужна только для повтора после ошибки.

В шапке видны этап и прогресс, во вкладке **«Прогоны»** — журнал этапов. Порядок этапов:

| Этап | Что происходит |
|---|---|
| Ключевые слова | модель составляет термины темы для отбора страниц в длинных документах |
| Извлечение | библиография статьи, затем по фрагментам по 1–3 страницы: дословная цитата → карточка доказательства |
| Проверка | код ищет цитату на странице и сверяет числа, единицы, минусы, отрицания и слова-антонимы, затем LLM-рецензент проверяет смысл |
| Группировка | повторы и противоречия внутри раздела КР; код запрещает опасные слияния (дети и взрослые, разные дозы) |
| Тезисы | формулировки «Рекомендуется / Не рекомендуется …»; УДД, УУР и проверку чисел и популяции считает код |
| Объединение | похожие тезисы из разных пакетов сливаются в один |

В конце сохраняется снимок результата. Он остаётся во вкладке «Прогоны» вместе с черновиком и
кнопками скачивания.

Можно закрыть браузер: обработка идёт на сервере. Если сервер остановить в процессе, полученное
сохранится. Повторное «▶ Обработать» доделает недостающее.

## 6. Посмотреть и поправить результат

| Вкладка | Что делать |
|---|---|
| **Карточки доказательств** | Фильтр «требует проверки» → открыть карточку: слева формулировка и цитата, справа страница PDF с подсветкой цитаты. Проверки: ✅ пройдено, ⚠️ на проверку, ❌ не найдено. Кнопки: «Подтвердить», «Отклонить», правка полей, «Объединить с…» |
| **Противоречия** | обе стороны с цитатами, поле решения (стороны не удаляются) |
| **Тезисы** | по разделам 103н: правка текста, УДД/УУР, «Утвердить», флаги ⚠ (что требует решения). Вверху вкладки — добавление экспертного тезиса |
| **Черновик и экспорт** | предпросмотр и скачивание: Word, Markdown, JSON (полный и по схеме преподавателя) |
| **Отчёт** | покрытие страниц, число запросов, токены, стоимость, ошибки |
| **Журнал правок** | все решения эксперта |

После правок карточек нажмите «▶ Обработать» ещё раз: тезисы пересоберутся, ваши правки
сохранятся. Если автоматика предложит другой вариант, появится жёлтый блок
«Принять новую / Оставить мою».

## 7. Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| «OAuth session expired» / «not logged in» | `claude auth login`, затем «▶ Обработать» с галочкой «только сбойные фрагменты» |
| Упёрлись в лимит подписки | дождаться сброса лимита и так же повторить со «только сбойные фрагменты»: полученное не теряется |
| Страница не открывается | проверить, что окно с `python -m krgen.server` открыто и в нём нет ошибки |
| Порт 8765 занят | сервер уже запущен в другом окне: закройте его |
