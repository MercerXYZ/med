# KRGen: как пользоваться

Как программа устроена внутри — в [README.md](README.md) и [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## 1. Где работать

**Сайт:** https://test.savkin.xyz. Сайт закрыт паролем, логин и пароль — у команды проекта.
Программа там уже запущена и сама обновляется из GitHub.

**На своём компьютере:**

```bash
pip install -r requirements.txt
claude auth login
python -m krgen.server
```

Затем откройте http://127.0.0.1:8765. Не закрывайте окно с сервером, пока идёт работа.

Модель работает на подписке Claude, каждый запрос расходует её лимиты. Ориентир по времени:

| Объём | Время |
|---|---|
| 1 короткая статья (5–15 стр.) | 2–4 мин |
| 3–5 статей | 10–20 мин |
| весь корпус (33 файла) | 2–3 часа, скорее всего упрётся в лимит подписки |

Для первого раза хватит 3–5 коротких статей из папки `Статьи Разбор клинреков`, например `311.pdf`,
`588.pdf`, `Caruso_и_др_2019_…pdf`, `Firth_и_Robertson_2017_…pdf`. Статьи можно добавлять и потом:
то, что уже обработано, берётся из кэша и повторно не оплачивается.

## 2. Создать проект

Кнопка **«Новый проект»** в шапке. Поля заполнены под нашу тему: тема, возрастная группа, коды
МКБ-10 через запятую, организация-разработчик. Нажмите **«Создать»**. Если код МКБ-10 записан с
ошибкой, под формой появится сообщение, окно останется открытым.

Проекты переключаются списком в шапке.

## 3. Загрузить статьи (окно 1 «Документы»)

Перетащите PDF в рамку или нажмите «выберите файлы». В таблице видно число страниц и статус файла:
«ожидает», «обработан», «частично», «ошибка», «дубликат», «нет текста». Наведите на статус, чтобы
увидеть подробности. Тот же файл второй раз не добавляется, а та же статья под другим именем или в
другой вёрстке помечается дубликатом и не обрабатывается. Сканы без текстового слоя не
обрабатываются (OCR нет).

## 4. Обработать

Кнопка **«Обработать»** в шапке. Рядом показываются текущий этап и полоса прогресса: ключевые слова,
извлечение фактов, проверка фактов, группировка, противоречия, сборка КР. По окончании будет
«Готово» или «Ошибка» (текст ошибки — при наведении).

Браузер можно закрыть: обработка идёт на сервере. Если она оборвалась, полученное сохраняется, а
повторное «Обработать» доделает недостающее.

## 5. Проверить факты (окно 2 «Факты»)

Сверху фильтры: статус, раздел КР, документ, поиск по тексту. Статусы:

- **подтверждённые** — цитата найдена, проверки пройдены, рецензент согласен, или факт подтвердили
  вы. Эти факты идут в КР;
- **на проверке** — есть сомнения. В КР не идут, пока вы их не подтвердите;
- **не подтверждённые** — цитата не найдена, числа в ней расходятся со страницей или рецензент
  считает, что цитата не подтверждает формулировку;
- **отклонённые** — отклонены вами.

Щелчок по факту открывает панель: формулировка, цитата, страница PDF с выделенной цитатой, источник
и список проверок (зелёный — пройдено, жёлтый — сомнение, красный — ошибка). Кнопки:

- «Подтвердить» — факт пойдёт в группы и КР, даже если автоматическая проверка в нём сомневалась;
- «Отклонить» — факт не используется;
- «Снять решение» — вернуть автоматический статус;
- «Изменить» — поправить формулировку, цитату, страницу, раздел КР и другие поля.

Правка сразу перепроверяет цитату и числа. Если поменялись поля, которые смотрел рецензент, факт
уходит «на проверку»: подтвердите его сами или запустите «Обработать» ещё раз.

Если после повторной обработки у изменённого вами факта появилась новая автоматическая версия,
показывается блок «Принять новую / Оставить мою».

## 6. Решить противоречия и проверить группы (окно 3)

**Противоречия** — сверху. У каждого две стороны A и B: факты с источником и УДД. Программа уже
предложила решение и написала причину:

| Причина | Решение |
|---|---|
| стороны про разных пациентов (дети и взрослые) | оставить оба |
| у одной стороны не осталось подтверждённых фактов | оставить оба |
| разные числа в описательном разделе (1.1–1.6, 7) | оставить оба |
| у одной стороны лучше УДД | верна эта сторона |
| УДД равны, а независимых источников больше хотя бы на 2 | верна сторона с большим числом источников |
| доказательства равной силы | решения нет, ждёт эксперта |

Выберите одно из четырёх: **«Оставить оба»**, **«Верно A»**, **«Верно B»**, **«Исключить оба»**.
Факты проигравшей стороны в КР не войдут; при «Исключить оба» не войдут обе стороны. Пока
противоречие не решено, факты обеих его сторон в КР тоже не идут. Ваше решение программа больше не
меняет, в том числе при повторной обработке.

**Группы** — ниже, по разделам КР. У группы формулировка, число фактов и источников, список фактов
(раскрывается). Щелчок по формулировке — правка; «Вернуть исходную» отменяет правку. Переключатель
«Не включать в КР» убирает группу из документа.

Решения и правки вступают в силу после сборки КР: появится подсказка с кнопкой **«Собрать КР»**.

## 7. Собрать и поправить КР (окно 4)

Кнопка **«Собрать КР заново»** пересобирает группы, противоречия и текст КР из текущих фактов. Это
быстрее полной обработки: статьи заново не читаются.

Окно показывает документ так же, как в Word: разделы по приказу 103н, тезисы с вводной фразой и
строкой «Уровень убедительности рекомендаций … (уровень достоверности доказательств – …)», ссылки
[n] на список литературы. Пустой раздел верхнего уровня выводится со строкой «Нет данных в
загруженных источниках.».

Щелчок по тезису открывает правку: вводная фраза, текст, УДД, УУР, комментарий. Кнопки «Сохранить»,
«Утвердить», «Отклонить», «Вернуть в черновик». Отклонённый тезис виден только в этом окне, в
выгрузку он не попадает. Ваши правки и утверждения сохраняются при пересборке; если пересборка дала
новый вариант правленого тезиса, в правке появится «Принять новую / Оставить мою». «Добавить
тезис» — свой тезис в выбранный раздел.

Под некоторыми тезисами мелким текстом стоят пометки, например «Числа не найдены в цитатах» или
«УДД не определён». Они только для вас, в Word не попадают.

Плашки вверху окна:

- «Есть изменения после последней сборки» — нажмите «Собрать КР заново»;
- «N противоречий ждут решения» — перейдите в окно 3 и решите их.

## 8. Скачать результат

В окне 4: **«Скачать Word»**, **«Markdown»**, **«JSON»** (полная выгрузка: документы, факты с
проверками, группы, противоречия, тезисы) и **«JSON по схеме kr_recommendation»** (по
`kr_recommendation.schema.json`). Рядом с последней кнопкой — результат проверки по схеме.

## 9. История

Ссылка **«История»** в шапке. Таблица прогонов: дата, статус, документы, факты, группы, тезисы,
запросы, стоимость. Щелчок по строке — сводка, журнал этапов и файлы снимка этого прогона (Word,
Markdown, JSON).

## 10. Если что-то пошло не так

| Что видно | Что делать |
|---|---|
| «Not logged in», «OAuth session expired» | на сайте — обновить токен на сервере ([deploy/README.md](deploy/README.md)); локально — `claude auth login`. Затем «Обработать» ещё раз |
| Закончился лимит подписки | дождаться сброса лимита и нажать «Обработать»: готовое берётся из кэша, полученное не теряется |
| В окне 1 «частично» или «ошибка» | кнопка «Повторить сбойные фрагменты» над таблицей |
| «нет текста» у документа | это скан без текстового слоя, его нужно распознать отдельно и загрузить заново |
| «Обработка уже идёт» | дождаться конца текущего прогона |
| В КР нет нужного факта | проверить в окне 2, что факт подтверждён, а в окне 3 — что его группа включена и противоречие решено, затем «Собрать КР заново» |
| Страница не открывается (локально) | проверить, что окно с `python -m krgen.server` открыто и в нём нет ошибки |
| Порт 8765 занят (локально) | сервер уже запущен в другом окне — закрыть его |
