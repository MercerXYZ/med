# KRGen: как пользоваться

Программа запускается с чистого листа: проектов, результатов и кэша нет. Ниже — как сделать первый
прогон и что смотреть в результате. Как программа устроена внутри — в [README.md](README.md).

## 0. Где работать

**Сайт (проще всего):** https://test.savkin.xyz, логин `root`, пароль `0000`.
Программа там уже запущена, токен Claude настроен, обновления с GitHub подтягиваются сами.

**На своём компьютере:**
```
pip install -r requirements.txt
claude auth login
python -m krgen.server
```
Затем откройте http://127.0.0.1:8765.

**Сколько это стоит.** Модель — Claude Haiku 5.5 на вашей подписке, уровень рассуждений `low`.
Расход идёт из лимитов подписки, ориентир:

| Объём | Время |
|---|---|
| 1 короткая статья (5–15 стр.) | 2–4 мин |
| 3–5 статей | 10–20 мин |
| весь корпус (33 файла) | 2–3 часа; скорее всего, упрётся в лимит подписки |

Для первого прогона возьмите 3–5 коротких статей, например `311.pdf`, `588.pdf`,
`Caruso_и_др_2019_…pdf`, `Firth_и_Robertson_2017_…pdf`, `minimally_angulated_pediatric_wrist_fractures_…pdf`
из папки `Статьи Разбор клинреков`. Статьи можно добавлять и позже: уже обработанное повторно не
оплачивается, потому что ответы модели кэшируются.

## 1. Создать проект

Кнопка **«+ Проект»** вверху справа. Поля уже заполнены под нашу тему:
- тема — «Переломы дистального отдела костей предплечья»;
- возрастная группа — взрослые и дети;
- коды МКБ-10 через запятую;
- организация.

Нажмите **«Создать»**. Если код МКБ указан с ошибкой, появится сообщение, а окно останется открытым.

## 2. Загрузить статьи

Вкладка **«Документы»**: перетащите PDF в рамку или выберите файлы. Сразу видно число страниц.
Одинаковые файлы помечаются как дубликаты, сканы без текстового слоя — как необработанные.

## 3. Запустить обработку

Кнопка **«▶ Обработать»** в шапке проекта. Галочки:
- **LLM-рецензент** — оставьте включённой: это смысловая проверка карточек;
- **Только сбойные фрагменты** — только для повтора после ошибки.

В шапке видны текущий этап и прогресс, а на вкладке **«Прогоны»** — журнал. Этапы идут так:

| Этап | Что происходит |
|---|---|
| Ключевые слова | модель составляет термины темы, чтобы отбирать страницы длинных документов |
| Извлечение | библиография каждой статьи, затем по фрагментам в 1–3 страницы: дословная цитата → карточка доказательства |
| Проверка | код ищет цитату на странице и сверяет числа, единицы, минусы, отрицания и антонимы; затем модель-рецензент проверяет смысл |
| Группировка | повторы и противоречия внутри раздела КР; код запрещает опасные слияния (дети и взрослые, разные дозы) |
| Тезисы | формулировки «Рекомендуется / Не рекомендуется …»; УДД, УУР, проверку чисел и популяции считает код |
| Объединение | похожие тезисы из разных пакетов сливаются в один |

В конце сохраняется снимок результата. Он остаётся на вкладке «Прогоны» вместе с черновиком и
кнопками скачивания.

Браузер можно закрыть: обработка идёт на сервере. Если она оборвётся, полученное сохранится, а
повторное «▶ Обработать» доделает недостающее.

## 4. Посмотреть и поправить результат

| Вкладка | Что делать |
|---|---|
| **Прогоны** | история прогонов: цифры, журнал этапов, черновик, скачивание. «Новый прогон» — копия проекта на выбранных статьях, исходный проект не меняется |
| **Документы** | статус каждого файла и полоса страниц: обработана, список литературы, вне бюджета, ошибка |
| **Карточки доказательств** | Фильтр «требует проверки» → открыть карточку. Слева формулировка и цитата, справа страница PDF с подсветкой цитаты. Проверки: ✅ пройдено, ⚠️ на проверку, ❌ не найдено. Кнопки: «Подтвердить», «Отклонить», правка полей, «Объединить с…» |
| **Противоречия** | обе стороны с цитатами и поле для решения; стороны не удаляются |
| **Тезисы** | по разделам 103н: правка текста, УДД и УУР, «Утвердить». Флаги ⚠ показывают, что требует решения. Вверху вкладки — добавление экспертного тезиса |
| **Черновик и экспорт** | предпросмотр и скачивание: Word, Markdown, JSON (полный и по схеме преподавателя) |
| **Отчёт** | покрытие страниц, число запросов, токены, стоимость, ошибки |
| **Журнал правок** | все решения эксперта |

После правок карточек нажмите «▶ Обработать» ещё раз: тезисы пересоберутся, а ваши правки
сохранятся. Если автоматика предложит другой вариант, появится жёлтый блок
«Принять новую / Оставить мою».

## 5. Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| «Not logged in» / «OAuth session expired» | на сайте: обновить токен на сервере (см. [deploy/README.md](deploy/README.md)); локально: `claude auth login`. Затем «▶ Обработать» с галочкой «только сбойные фрагменты» |
| Упёрлись в лимит подписки | дождаться сброса лимита и повторить с галочкой «только сбойные фрагменты»: полученное не теряется |
| Страница не открывается (локально) | проверить, что окно с `python -m krgen.server` открыто и в нём нет ошибки |
| Порт 8765 занят (локально) | сервер уже запущен в другом окне — закройте его |
