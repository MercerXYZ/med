# KRGen — черновик клинической рекомендации из научных статей

Учебный прототип по ТЗ «Система подготовки клинических рекомендаций из научных статей».
Принимает PDF научных статей по теме, извлекает **подтверждённые источниками** клинические
утверждения (карточки доказательств с дословной цитатой и страницей PDF), проверяет цитаты,
числа, отрицания и смысл, объединяет повторы, показывает противоречия, собирает тезисы
по разделам приказа № 103н и выгружает черновик в Word, Markdown и JSON.

> Результат — черновик для экспертной проверки. Не предназначен для лечения пациентов.

Как пользоваться: [docs/USAGE.md](docs/USAGE.md).
Подробно о методе и обосновании: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
Правила разметки эталона: [docs/ANNOTATION_GUIDE.md](docs/ANNOTATION_GUIDE.md).
Схема экспорта: [schemas/krgen_export.schema.json](schemas/krgen_export.schema.json)
(+ совместимый экспорт по `kr_recommendation.schema.json` с автоматической валидацией).

## Установка

Требуется Python 3.11+ и установленный Claude Code CLI с входом по **подписке** Claude
(API-ключ не нужен и не используется).

```bash
pip install -r requirements.txt
```

```bash
claude auth login
```

## Запуск интерфейса

```bash
python -m krgen.server
```

Откройте http://127.0.0.1:8765 → «+ Проект» → загрузите PDF на вкладке «Документы» → «▶ Обработать».

Вкладки: **Документы** (статус и покрытие каждой страницы), **Карточки доказательств** (цитата,
подсветка на изображении страницы, результаты проверок, подтверждение/отклонение/правка/объединение),
**Противоречия**, **Тезисы** (правка формулировки, УДД/УУР, критерии качества, экспертные тезисы),
**Черновик и экспорт**, **Отчёт** (покрытие, запросы, токены, стоимость, ошибки, метрики),
**Журнал правок**.

## Консольный режим

```bash
python -m krgen.cli init --id demo --title "Переломы дистального отдела костей предплечья" --age mixed --icd S52.5 S52.6 S52.8 --org "АТОР"
```

```bash
python -m krgen.cli add demo "Статьи Разбор клинреков/crawford2012.pdf" "Статьи Разбор клинреков/Caruso_и_др_2019_Below_elbow_or_above_elbow_cast_for_conservative.pdf"
```

```bash
python -m krgen.cli run demo
```

```bash
python -m krgen.cli export demo out
```

Оценка по эталону и эксперимент:

```bash
python -m krgen.evaluate demo gold/example_gold_p1.json
```

```bash
python -m krgen.experiment experiments/thinking_and_gate.json
```

## Конфигурация

Переменные окружения (или `config.json` в корне с теми же именами полей, что в `krgen/config.py`):

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `KRGEN_MODEL` | `claude-haiku-4-5` | модель извлечения и синтеза |
| `KRGEN_JUDGE_MODEL` | `claude-haiku-4-5` | модель-рецензент |
| `KRGEN_THINKING` | `0` | бюджет extended thinking (0 — выкл.) |
| `KRGEN_CONCURRENCY` | `4` | параллельных запросов |
| `KRGEN_DATA` | `./data` | БД, загрузки, кэш ответов модели |
| `KRGEN_FAIL_AFTER` | — | тестовый сбой: после N запросов API «падает» |
| `KRGEN_CLAUDE_CLI` | `claude` из PATH | путь к Claude Code CLI |

`config.example.json` — пример файла настроек без секретов.

## Демонстрационные сценарии ТЗ

| Сценарий | Где |
|---|---|
| Несколько PDF → карточки со страницей и цитатой | Документы → Обработать → Карточки (подсветка цитаты на странице, ссылка на PDF#page) |
| Диагностические и лечебные утверждения, отрицание/ограничение | Карточки, фильтр по разделу 2.x / 3.x; проверка «Отрицания» |
| Объединение повторов без потери источников | Карточка → «Объединённые повторы»; тезис → список доказательств |
| Противоречие без удаления стороны | Вкладка «Противоречия» |
| Правка → сохранение → повторная обработка | Правка карточки/тезиса, «Обработать»: правка сохраняется, новая автоверсия — для сравнения |
| Экспертное дополнение | Тезисы → «Добавить экспертный тезис» (фиолетовая метка, без цитаты) |
| Выгрузка JSON, текста, Word | Черновик и экспорт |
| Длинный документ: покрытие/пропуски | Документы (полоса страниц), Отчёт → «Покрытие документов» |
| Тестовый сбой | `KRGEN_FAIL_AFTER=5 python -m krgen.server` → «Обработать» → документы `partial`/`error` с сообщением, полученное сохранено; затем без переменной «только сбойные фрагменты» |

## Структура

```
krgen/
  config.py      настройки, версии промптов
  db.py          SQLite: auto/override/pending_auto, журнал правок
  pdf_ingest.py  PDF → страницы, дубликаты, бюджет страниц, подсветка цитаты
  llm.py         Claude Agent SDK (подписка), кэш, повторы, учёт токенов, тестовый сбой
  prompts.py     промпты и JSON-схемы ответов
  extract.py     библиография, извлечение карточек
  verify.py      детерминированные проверки + LLM-рецензент
  cluster.py     повторы и противоречия со «стражами»
  synth.py       тезисы, УДД/УУР, критерии качества
  pipeline.py    оркестрация, статусы, отчёт
  export.py      JSON / kr_recommendation / Markdown / Word (103н)
  evaluate.py    P/R/F1, проверяемость цитат, повторы
  experiment.py  сравнительные эксперименты
  server.py, static/  веб-интерфейс
gold/            эталоны
experiments/     спецификации экспериментов
docs/            архитектура, правила разметки, отчёт
```
